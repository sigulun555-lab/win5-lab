# WIN5 予想・市場本命・事後評価の運用ルール

更新日：2026-10-24 JST

## 1. 予想の固定と役割の区別
- GPT/Claudeの◎は各モデルが締切前に出した予想上の本命とする。市場本命（単勝オッズ最小馬）と同義にしない。
- 市場本命は別列に記録し、オッズの取得時刻・公式ソース・対象レースを必須とする。
- 予想を比較するときはモデル予想の作成時刻を変更せず、比較用市場オッズの基準時刻を揃える。例：公式発売締切14:45なら14:40の公式オッズを市場ベンチマークとし、実際に取得した時刻とオッズ時点を記録する。
- 締切後のオッズや結果で、締切前の◎・確率・上位3頭を変更しない。

## 2. V1・V2・市場の記録
- V1：締切前に保存した元予想。確率・順位・取得時刻を固定し、上書きしない。
- V2：締切後に観測されたオッズ変動を反映した事後試算。独立したGPTモデルではなく、正式な締切前予想・的中成績に含めない。
- 市場：固定時刻の公式単勝オッズをレース内で正規化した確率・人気順位。モデル予想とは別に評価する。
- V2の注記「市場情報を反映したシナリオであり、独立に学習・生成したGPTモデルではない」は削除しない。

## 3. 的中判定
- WIN5の各レース的中は1着馬のみ。2着・3着は1着的中に数えない。
- ◎的中、◎○▲（上位3候補）に1着馬が含まれるか、WIN5全体5レース的中を別指標にする。
- WIN5全体の払戻金・的中票数はJRA公式情報を取得できた場合のみ記録し、未取得は未取得とする。
- 比較は同じ定義・同じ開催のスナップショットに限定し、5レース程度の小標本でモデルの優劣を断定しない。
