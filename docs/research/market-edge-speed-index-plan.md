# 市場オッズを上回るWIN5予測情報の検証計画

- ステータス: 実験提案（本番モデル未採用）
- 対象: WIN5各対象レースの全出走馬の1着確率
- 基準モデル: 締切前オッズをレース内で正規化した市場確率
- 作成日: 2026-11-14
- 重要: 本文の市場成績（対数損失 約2.12、最上位的中 8/25）は、今回の検討でユーザーから提示された値。元データ・集計コードによる独立再計算はまだ行っていない。

## 1. 目的と現状認識

市場オッズの正規化確率をベースラインとして固定し、市場に含まれていない、または市場が十分に評価できていない情報を追加することで、各馬の1着確率を改善できるか検証する。

現状の参考値:

| 指標 | 市場ベースライン |
|---|---:|
| 対数損失 | 約2.12 |
| 最上位的中 | 8/25（32%） |
| 評価レース数 | 25 |

この25レースだけでは改善の有無を統計的に判断するには小さい。今後は同じレース集合・同じ結果・同じ確率定義で比較し、時系列のアウト・オブ・サンプル評価を行う。

## 2. 市場に上積みできる可能性のある情報

優先仮説は「市場と異なる尺度で測った、条件補正済みの競走能力」である。単純な人気・オッズ順位や、一般に知られた傾向を追加するだけでは、市場情報との重複が大きい可能性がある。

| 情報候補 | 期待する上積み | 注意点 |
|---|---|---|
| 近走の能力・スピード指数 | 高め | 時計の出やすさ、相手関係、条件差を補正する |
| 馬場適性 | 中〜高 | 馬場状態の分類とサンプル数に注意 |
| 距離適性 | 中〜高 | 距離変更と過去走の条件差を扱う |
| 展開・ペース適性 | 中程度 | ペース予測自体の誤差がある |
| コース形態適性 | 中程度 | コース別の過学習を避ける |
| 騎手・厩舎情報 | 低〜中 | 公開情報であり市場に反映済みの可能性 |
| 人気・オッズ順位 | 低い | 市場ベースラインと情報が重複 |

ここでの「期待」は検証前の仮説であり、実証済みの効果ではない。

## 3. 一般的な馬券戦略と予測精度を分離する

### 少頭数のレースを狙う

少頭数では候補が絞られ、レース単位の的中確率が高くなる場合がある。しかし、頭数は公開情報で市場にも反映されるため、「少頭数」というだけで市場を上回る情報とは限らない。

検証するなら、頭数による選別そのものではなく、頭数・人気構成などの条件別に市場確率の校正誤差が残るかを調べる。

### 本線と抑えを分ける

これは主に買い目構成・資金配分の戦略であり、馬ごとの1着確率の推定精度を直接改善するものではない。予測モデルの改善と買い目最適化は別の実験として扱う。

- 予測精度: 市場より正確な各馬の1着確率を作れるか
- 馬券戦略: 同じ確率を使って買い目や資金配分を改善できるか

今回の実験では予測精度のみを対象とし、買い目最適化は行わない。

## 4. 次に試す実験は1つに限定する

### 仮説: 馬場・距離・クラス補正済みの近走スピード指数

直近3走の走破時計を、当日の馬場差、距離、競馬場、クラス・相手関係などで補正した指数にする。着順や人気だけでは分かりにくい走破能力を表現し、市場確率に追加する。

例: 前走5着でも、上位馬と僅差で、レベルの高いレースを走っていた馬を、着順だけの場合より適切に評価できる可能性がある。

この仮説は未検証。指数の定義・補正方法は結果を見てから変更せず、学習期間内で決めて固定する。

### 必要なデータ

1. 各出走馬の直近3走の走破時計
2. 各過去走の距離・競馬場・馬場状態
3. レースのクラスおよび相手関係を評価するための情報
4. 予測対象レースの全出走馬と、予測時点で取得した締切前オッズ
5. 実際の1着馬（正解ラベル）

取得できない項目は推測で補完せず、欠損として記録する。出走取消・競走除外の扱い、オッズ取得時刻、確率の正規化方法も固定する。

## 5. 実験設計（結果を見る前に固定）

| 項目 | 事前ルール |
|---|---|
| 基準モデル | 締切前オッズをレース内で正規化した市場確率 |
| 追加モデル | 市場確率に補正済みスピード指数を追加 |
| 追加特徴量 | スピード指数のみ。他の特徴量は同時追加しない |
| 対象 | 全出走馬。少頭数などの事後的な対象選別はしない |
| 学習・調整 | 過去データのみ。未来のレース情報を使わない |
| 評価 | 時系列順のアウト・オブ・サンプル検証 |
| 比較 | 同一レース集合・同一結果で市場単独と追加モデルを比較 |
| 本番反映 | 合格条件を満たすまで行わない |

### データ漏洩防止

- 予測時点で利用可能だった情報だけを使う。
- 指数の基準値・補正係数・モデル係数は各検証時点より前のデータで推定する。
- 締切後オッズやレース結果を特徴量に混ぜない。
- 同じレースの情報が学習側と評価側にまたがらないようにする。
- 欠損処理や対象除外のルールを事前固定する。

## 6. 合格条件・評価指標

暫定的な事前合格条件:

| 項目 | 条件 |
|---|---|
| 対数損失の目標 | 市場基準 約2.12に対し、平均2.10以下を目指す |
| 統計的な確認 | レース単位の損失差について、対応のある比較と95%信頼区間を提示する |
| 信頼区間 | 改善幅（市場損失 − 追加モデル損失）の95%信頼区間下限が0を上回ることを目標とする |
| 再現性 | 3つ以上の時系列評価期間で改善方向 |
| 補助指標 | 最上位的中率、確率校正、人気順位別成績も報告 |

2.10は実験上の目標であり、改善の保証や統計的有意性を意味しない。評価レース数が少ない場合、信頼区間は広くなる。25レースだけで採否を決めない。必要に応じて数百レース規模まで評価対象を拡大する。

対数損失の定義は、各レースについて全出走馬の勝率を合計1に正規化し、実際の勝ち馬に割り当てた確率の負の自然対数を計算し、レース間で平均する方式を基本案とする。既存の「約2.12」が別の集計定義なら、比較前に既存定義を確認し、両モデルに同じ定義を適用する。

最上位的中率は各レースで予測確率最大の馬が勝った割合とする。同率の場合の扱いも実装前に固定する。

## 7. 実行順序

1. 現行の市場確率と評価コードを確認し、対数損失2.12の算出定義・対象25レースを再現する。
2. 市場ベースラインを固定し、変更不可の比較対象として保存する。
3. スピード指数の算出仕様を定義し、過去データだけで作成する。
4. 時系列アウト・オブ・サンプル検証を実施する。
5. 市場単独との損失差、95%信頼区間、期間別成績、校正を報告する。
6. 合格条件を満たした場合のみ、別PRで本番候補として提案する。現行本番モデルは自動変更しない。

## 8. 結論

次の一手は、少頭数狙いや本線・抑えの工夫ではなく、**馬場・距離・クラス補正済みの近走スピード指数を、市場確率に1つだけ追加して検証すること**とする。

市場オッズ正規化は引き続き基準モデルとして保持する。仮説が外れた場合も結果を記録し、根拠なく特徴量を追加し続けない。予測精度と馬券戦略を混同せず、実証された改善だけを本番に反映する。
