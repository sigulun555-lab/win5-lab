# WIN5 ◎○▲の必須出力ルール

## 目的

WIN5対象5レースすべてで、◎（本命）・○（対抗）・▲（単穴）を必ず表示し、予想の記録と確率モデルの評価を混同しない。

## 必須ルール

- 5レースそれぞれ3頭、合計15枠を出力する。
- 各印に馬番・馬名・勝率を付ける。
- 同一レース内で同じ馬を複数の印に割り当てない。
- 全頭確率モデルがある場合、◎○▲は既存の確率を降順に並べた上位3頭とする。表示用に確率を作り直したり変更したりしない。
- 同率の場合は馬番の小さい順で表示し、同率だったことを警告する。
- 全頭確率がない暫定予想でも◎○▲は記録できるが、その記録をLog lossやBrier scoreの評価対象にしない。
- 元の予測CSVは変更・上書きしない。予測の作成時刻が証明できなければ「不明」と記録し、発走前予測として正式なバックテストに含めない。
- 結果を見た後で過去の印・確率を変更しない。訂正が必要なら新しい版として別ファイルに保存し、理由と時刻を記録する。

## 全頭確率CSVから◎○▲を作成する

```bash
python scripts/export_win5_three_picks.py \
  --input data/win5_joint/2026-10-25/gpt-exploratory-history-only-probabilities.csv \
  --output data/win5_joint/2026-10-25/gpt-exploratory-three-picks.csv \
  --date 2026-10-25 \
  --probability-column gpt_exploratory_win_probability_pct \
  --leg-column leg \
  --horse-column horse_number \
  --name-column horse_name
```

出力CSVには15頭分の印、馬番、馬名、勝率、元CSVのSHA256を記録する。出力先ファイルがすでに存在する場合は上書きせず停止する。元の全頭確率CSVは変更しない。

**注意：** この処理は確率表の上位3頭を表示するだけであり、予測モデルの精度を改善したり、予測作成時刻を証明したりするものではない。

## 評価の区別

- Top-1：◎が勝ったか。
- Top-3：◎○▲のいずれかが勝ったか。
- Log loss / Brier score：全頭の確率がそろい、結果と対応できる場合だけ計算する。
- 市場オッズ由来の列は市場ベンチマークとして表示し、独立モデルの実績として数えない。
