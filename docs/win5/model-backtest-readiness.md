# WIN5確率モデルの検証準備

## 今回追加したもの
- `scripts/evaluate_win_probabilities.py`: レースごとの全馬確率と実際の勝ち馬ラベルから、平均Brier score（レース内ランナー平均）、勝ち馬log loss、1位馬的中率、簡易キャリブレーション表を出力するスクリプト。
- このスクリプトは結果データを取得せず、モデルを自動で検証済みにするものではない。

## 現状
2026-10-25の探索的確率と市場確率のCSVは存在するが、過去開催の各レースについて全出走馬の当時の予測確率・当時点の市場確率・実際の勝ち馬を揃えた時系列検証用データセットはまだない。したがって、今は実測Brier score / log loss / 的中率を報告できない。

## 検証データに必要な列
`date,race_key,horse_number,probability,actual_winner`
比較する市場ベースラインにも同じレース・出走馬・時点のデータが必要。各レースに勝ち馬ラベルが1頭だけあること、確率合計が100%であることを確認する。

## 運用ルール
1. 過去の開催日を時系列で train / validation / test に分ける。
2. 係数調整は train のみ、モデル選択は validation のみ、最終評価は一度だけ test で行う。
3. 市場確率とGPTモデルは同じ出走馬集合・同じ予測時刻で比較する。
4. Brier scoreとlog lossは低いほど良い。1位的中率だけで結論を出さない。
5. 現在の探索モデルは検証が終わるまで「未検証」と明示する。

## 2026-10-24の単日事後評価（再計算確認済み）

```text
入力予測: data/win5_joint/2026-10-24/win5_gpt_v2_scenario.csv (72頭、5レース)
結果:     data/win5_joint/2026-10-24/win5_result.csv (5レース)
既存レポート: reports/win5-result-evaluation-2026-10-24.md
```

予測CSVと結果CSVを読み直し、各レースで勝ち馬が一頭だけ一致すること、各モデルの確率合計がレース内100%であることを検査して、指標を独立に再計算した。

| 系統 | Top-1 | 勝ち馬Log loss平均 | Brier（馬単位平均） |
|---|---:|---:|---:|
| GPT V1（11:06時点の推定） | 2/5 (40%) | 2.03361 | 0.057290 |
| GPT V2（市場補正・事後シナリオ） | 1/5 (20%) | 2.02031 | 0.057307 |
| 市場確率列 | 1/5 (20%) | 2.02536 | 0.057251 |

- 再計算値は既存レポートと一致した。
- これは5レースのみの単日評価であり、モデル優劣を結論づける標本数ではない。
- V2は市場情報を取り込んだ事後シナリオであり、独立GPTモデルとして扱わない。
- 市場確率列は予測CSVの記録上、最新観測オッズ（JRA公式、14:39〜14:40 JST）を使った列。一方、GPT V1の情報時刻は11:06 JSTのため、同一時点比較ではない。市場との厳密比較には、V1と同じ時点の市場スナップショットが必要。
- 現在確認できた予測・結果の組は2026-10-24の1開催分。複数開催をまたぐ時系列バックテストや未使用のテスト期間での評価は未実施。
