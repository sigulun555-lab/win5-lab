# GPT独立予想の探索的ベースライン：計算式（2026-10-25）

## 状態・用途

これは履歴データのみを使った **v0探索用ベースライン** です。予測精度は未検証で、校正済みの真の勝率ではありません。購入判断用の完成モデルと混同しないでください。

- 入力：`data/horse_history/2026-10-25.json`（取得時刻：2026-10-24 18:04:26 JST）
- 出力：`data/win5_joint/2026-10-25/gpt-exploratory-history-only-probabilities.csv`
- 対象：WIN5全5レース、75頭
- 当日市場オッズとClaude予想は、この履歴のみの確率計算には混ぜていません。

## 1. 直近走の順位パーセンタイル

各馬について、直近最大6走を使用します。直近の走りほど大きい重みを付けます。走 (i) の重みは（(i=0) が最新走）：

`w_i = 0.78^i`

そのレースの出走頭数を (N_i)、着順を (R_i) とすると、順位パーセンタイルは：

`P_i = (N_i - R_i) / (N_i - 1)`

1着なら1、最下位なら0に近い値になります。(N_i > 1) の記録のみ計算できます。

加重平均順位パーセンタイル：

`P = Σ(w_i × P_i) / Σ(w_i)`

## 2. レーティング平均

過去走のレーティングが数値で存在する記録だけを対象に、同じ (w_i=0.78^i) を使って加重平均します。

`T = Σ(w_i × rating_i) / Σ(w_i)` （レーティングが数値である走のみ）

数値レーティングが1件もない馬は、レーティング補正を0とします。

## 3. 馬ごとのヒューリスティックスコア

`score = (P - 0.5) × 2.1 + (T - 90) × 0.025`

レーティング欠損馬については第2項を0にします。係数（2.1、0.025、基準値90）は仮置きで、最適化・検証済みの係数ではありません。

## 4. 同一レース内で勝率風スコアを確率に変換

レース内の馬 (h) のスコアを (s_h)、そのレースの最大スコアを (s_{max}) とします。

`q_h = exp((s_h - s_max) × 1.35)`

`p_h = q_h / Σ_j(q_j) × 100%`

各レース内で全出走馬の (p_h) が合計100%になるよう正規化します。CSVの確率列は小数点以下6桁に丸めているため、表示値の合計にはごく小さな丸め誤差が出る場合があります。

**重要：** これはスコアを相対的に配分した値であり、実際の勝率として校正済みではありません。レースごとの相対比較用の暫定値です。

## 計算の流れ（擬似コード）

```text
for each horse in each WIN5 leg:
    use up to 6 most recent historical runs
    weight each run by 0.78 ** recency_index
    P = weighted_mean((field_size - finish_position) / (field_size - 1))
    if numeric ratings exist:
        T = weighted_mean(rating, using only runs with numeric ratings)
        score = (P - 0.5) * 2.1 + (T - 90) * 0.025
    else:
        score = (P - 0.5) * 2.1
for each leg:
    q = exp((score - maximum_score_in_leg) * 1.35)
    probability_pct = q / sum(q for all horses in leg) * 100
```

## この計算に含めていないもの

- 距離適性、コース適性、芝・ダート、馬場状態、クラス差
- 斤量、騎手、展開、枠順、馬体重、当日取消・除外の補正
- 市場オッズ、人気、他モデルの予想

過去走が少ない馬、レーティングが欠けている馬、条件が大きく変わる馬では特に不確実性が高くなります。

## 検証方針

過去開催を日付順に分け、予測時点より後の情報を学習・入力に混ぜない時系列ホールドアウトで評価します。市場ベンチマークは各馬の逆数オッズをレース内で正規化して作り、モデルと同じ対象レースで比較します。評価指標は Log loss、Brier score、Top-1（◎相当）の的中率、Top-3（◎○▲のいずれか）の的中率です。検証が終わるまでは「的中率が高い」「精度確認済み」とは表現しません。

## ◎○▲の決め方との関係

全頭確率がある場合、原則として確率の高い順に上位3頭を ◎・○・▲ とします。これは表示ルールであり、スコア式自体を変更する操作ではありません。根拠の弱さは別途注記し、順位を手作業で入れ替えた場合は理由を記録します。
