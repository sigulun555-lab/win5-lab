# GPT朝の確率の温度調整（較正）の確認

- 対象：2026-10-31・2026-11-01 の WIN5 対象5レースずつ（計10レース）
- 方法：GPT確率 p を p^(1/T) で作り直し、レース内で合計100%に正規化。T が小さいほど、確率を尖らせる
- 指標：1着馬に割り当てた確率の対数損失（小さいほど良い）

| T | 10/31 | 11/1 | 両日 |
|---|---|---|---|
| 1.0（較正なし） | 2.026 | 2.063 | 2.044 |
| 0.7 | 1.969 | 1.992 | 1.980 |
| 0.5 | 1.968 | 2.013 | 1.991 |

日をまたいだ確認（片方の日でTを決め、もう片方で確かめる）：
- 10/31でTを決めて11/1で確認：2.063 → 2.013（T=0.5）
- 11/1でTを決めて10/31で確認：2.026 → 1.969（T=0.7）

市場確率（v0）の同10レースは 1.962。較正後のGPT（T=0.7）は 1.980 で、市場との差は小さくなりました。

注意：
- 10レースの暫定値です。Tの値は、今後の新しいデータで確かめるまでは確定ではありません。
- 結果を見てからTを決めた比較です。今後は、毎回の記録の中で、事前に決めた方法で評価します。
