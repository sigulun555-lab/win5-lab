# B2競馬場名エイリアス監査（2026-10-25）

## 判断

- `名古` → `LOCAL`：明示エイリアスとして登録。監査サンプルには「名古屋大賞典」「C17組」など、名古屋競馬場と整合するレース名が複数あり、元の履歴ラベルが省略形と判断できる。ただし、元データの値自体は変更しない。
- `米` → `UNCLASSIFIABLE`：1件のみでラベルが短く、競馬場を一意に確定できる証拠が不足しているため保留。米国開催と推測して海外扱いにしない。

## 運用

- エイリアス定義は `research/factor-validation/b2_venue_aliases.json`。
- `classify_venue` は自動で曖昧な文字列を推測しない。呼び出し側がこのJSONを明示的に読み込んで渡した場合に限り、エイリアスが適用される。
- この対応付けは分類用であり、履歴JSONの原文を修正しない。
- B2学習データ作成時は、未分類ラベルを件数・例とともに報告し、未分類のまま残す。

## 根拠と限界

GitHub Actionsの履歴監査で、競走記録4,314件のうち、対応付け要確認ラベルは `名古` 21件、`米` 1件だった。`名古` は監査例に含まれるレース名を根拠に分類した。全21件の開催場を公式の個別結果ページで独立照合したわけではないため、学習前に該当行の確認を続ける。これはデータ分類上の暫定判断であり、モデル性能の検証ではない。
