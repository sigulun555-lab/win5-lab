## 1. 入力と前処理

1. 各対象レースの発走前に利用可能な過去走のみを使い、未来情報・当該レース結果を使わない。履歴ページが後日取得された場合は、各対象レース日より前の走だけを残す（`run.date < target_race.date`）。対象日以降の成績は必ず除外する。
2. 数値着順でない走（中止・失格等）および出走頭数 N <= 1 の走を、直近走の選択前に除外する。
3. 重み下げ候補では、残った全管轄の走から新しい順に最大6走を選ぶ（最新 i=0）。地方除外候補では、地方走を除外してからJRA走の新しい順に最大6走を選ぶ。地方除外を直近6走選択後に行う実装は禁止。
4. 基本の走重みは `w_i = 0.78^i`。
5. 着順パーセンタイルは `P_i = (N_i - R_i)/(N_i - 1)`。
6. クラス区分は `DEBUT`（新馬）、`MAIDEN`（未勝利）、`1WIN`、`2WIN`、`3WIN`、`OP_L`、`GRADED`、`UNKNOWN_JRA`、`LOCAL`、`OVERSEAS`、`UNCLASSIFIABLE`。基準カテゴリは `DEBUT`。地方・海外・区別不能はクラス交互作用 `gamma=0` とし、地方効果は地方走にのみ適用する。
7. JRA走の名称のみのクラス（例：「三宮S」）は、当該対象走より前に利用可能なJRA結果データ（学習データ範囲内）を日付・競馬場・1着馬で照合してクラス付与する。照合ルールと一意一致条件をコード化し、複数一致・不一致は `UNKNOWN_JRA` とする。結果を見て手作業で割り当てない。`UNKNOWN_JRA` は独立係数を学習するカテゴリとし、係数0と仮定しない。
8. 競馬場名が空欄の走は `UNCLASSIFIABLE` とし、`gamma=0`、地方係数対象外。短縮・切れた競馬場名（例「名古」「サウ」）の地方／海外／JRA判定は、検証前に固定した明示的な別名辞書で行う。辞書に一致しない値は推測せず `UNCLASSIFIABLE` とする。辞書ファイルとSHA256を記録する。
9. 地方走にクラス情報がない場合も、地方走をJRAクラスに推測変換しない。外国馬は履歴ページの直近4走制限をデータ制約として記録し、取得できない過去走を補完・推測しない。

## 2. 候補式と学習

基本値 `x_i = 2.1 * (P_i - 0.5)` とし、

`S_raw(h) = sum_i w_i * [x_i + gamma[class_i] * (P_i - 0.5) + eta_LOCAL * I(local_i) * x_i] / sum_i w_i`

とする。

- `gamma[class_i]` はクラス別交互作用係数。基準カテゴリ `DEBUT` は0に固定し、他カテゴリ係数は学習データだけから推定する。`UNKNOWN_JRA` も独立カテゴリとして推定する。
- 地方走除外候補では地方走を直近6走選択前に除外し、`eta_LOCAL=0` とする。
- 地方重み下げ候補では地方走を含めて直近6走を選び、地方走にのみ `1 + eta_LOCAL` を掛ける。`eta_LOCAL` は学習データのみで推定し、実効重みを [0,1] に制約する。
- 係数は、学習期間の各レース勝者を目的変数とするレース内softmax（条件付き多項ロジット）の対数尤度最大化で推定する。レース単位でデータを分け、同一レースの馬が学習・検証にまたがらないようにする。
- 正則化L2探索値を `{0.001, 0.01, 0.1}` に固定する。切片は使用せず、基準カテゴリ制約を含む係数にL2を適用する。選択規則は学習期間内rolling-origin検証の平均対数尤度最大（同点は大きいL2）とする。
- 温度 `tau` は全候補に共通の定義 `p_h = exp(S_h / tau) / sum_j exp(S_j / tau)` で使用し、学習期間内だけで推定する。探索範囲は `tau ∈ {0.25, 0.5, 0.75, 1.0, 1.25, 1.5, 2.0, 3.0}` とし、学習期間内rolling-origin検証の平均対数尤度最大（同点は1.0に近い値）を選ぶ。数値安定化のため最大スコアを引いて指数化する。
- 現行Bの温度相当係数1.35を変更したと見なさないよう、`B0-original` は現行式・現行確率をそのまま再現し、`B0-refit` は同じBスコアに対して上記の共通手順でtauのみ再推定した比較用候補として別に記録する。

### JRA実績数による縮小

`nJ_h` は、候補ごとに選択された最大6走の中にあるJRA走数とする（全履歴件数ではない）。地方除外候補では選択されたJRA走数、地方重み下げ候補では選択された6走内のJRA走数を数える。

`S_shrunk(h) = [nJ_h / (nJ_h + k)] * S_base(h)`

- `k` の探索値を `{0, 1, 2, 3, 5, 8}` に固定し、学習期間内rolling-origin検証の平均対数尤度最大（同点は小さいk）で選ぶ。
- JRA未出走はスコア0（中立）。走数縮小の有無を別候補として評価する。

### レーティング

レーティングあり候補は、選択された走のうちJRA数値レーティングがある走だけから加重平均 `T_h` を求め、`rho * (T_h - 90)` を加える。`rho` は学習期間だけで推定する。JRAレーティングがない馬（JRA未出走を含む）はレーティング項を0とする。レーティングなし候補では全馬この項を0とする。レーティング件数・対象走数・欠損率を候補別に報告し、検出力が低い場合は結論を保留する。

最終スコアは `S(h) = S_shrunk(h) + rho * (T_h - 90)`（レーティングなし候補は `rho=0`）。確率は共通温度を用いたレース内softmaxで正規化する。

## 3. 別々に評価する候補

- `B0-original`：現行Bを元の式・確率で再現。ファイルは変更しない。
- `B0-refit`：現行Bスコアに共通の学習期間推定tauを適用。
- `B2-a`：クラス交互作用のみ。
- `B2-b1`：地方走を選択前に除外。
- `B2-b2`：地方走を含む直近6走選択後、地方走だけ実効重みを下げる。
- `B2-c`：JRA走数による縮小（kの事前固定探索）。
- `B2-d`：レーティングあり／なし。
- `B2-full`：クラス→走数縮小→地方処理の順に追加し、レーティングあり／なしは別々に出す。
- 各候補について、元のスコアの比較と、共通tau適用後の比較を混同せず記録する。

候補を混ぜて単一の「B2」と呼ばない。検証結果を見て候補や探索範囲を追加・変更しない。

## 5. データ元・取得可能性・完全性

- `collector/horse_history.py --date YYYY-MM-DD --out data/horse_history` は指定日の出馬表に載る馬について現行のJRA公式競走馬情報ページを取得するため、過去日の出馬表を直接取得する用途には使えない。過去検証は、過去1年のJRA結果データに含まれる馬IDを起点に取得した競走馬情報ページ群を使用する。取得完了後、取得馬数・成功数・欠損数・取得元・取得時刻・出力SHA256を記録する。
- 地方競馬の走歴は競走馬情報ページに含まれることが確認されているが、地方走のクラス情報はない。地方クラスは推測しない。
- 各対象走の特徴量は、対象レース日より前の走だけに切り詰める。未来走の混入がないことを自動テストし、漏洩チェック件数を記録する。
- 入力、別名辞書、仕様、実装、出力それぞれのSHA256を実行記録に保存する。取得時刻不明は `unknown` とする。欠損・照合失敗は除外して隠さず、件数と割合を報告する。
- 10/25入力でクラス名のみの走が約31%、競馬場名空欄が47件というレビュー時点の観測を、検証対象データで再集計して報告する。これらの件数は確定値としてハードコードしない。
