# B2検証用モデル仕様（事前固定・予測出力なし）

- 作成時刻：2026-10-25 13:04:40 JST
- 状態：仕様のみ。係数推定・予測出力・有効性確認は未実施。正式表示版ではない。
- 目的：現行Bを上書きせず、クラス差・地方競馬履歴・JRA実績数・レーティング有無を検証する。

## 1. 入力と前処理

1. 各対象レースの発走前に利用可能な過去走のみを使い、未来情報・当該レース結果を使わない。履歴ページが後日取得された場合は、各対象レース日より前の走だけを残す（run.date < target_race.date）。ページに表示される対象日以降の成績は、必ず除外する。
2. 数値着順でない走（中止・失格等）および出走頭数 N <= 1 の走を、走数選択前に除外する。
3. 新しい順に最大6走、重みは `w_i = 0.78^i`（最新 i=0）。
4. 着順パーセンタイルは `P_i = (N_i - R_i)/(N_i - 1)`。
5. クラス区分は新馬・未勝利・1勝・2勝・3勝・OP/L・重賞。地方競馬は `jurisdiction=LOCAL` としてJRAと分離する。不明値は推測で補完しない。

## 2. 候補式

基本値 `x_i = 2.1 * (P_i - 0.5)` とし、クラスと地方の効果を次で表す。

`S_raw(h) = sum_i w_i * [x_i + gamma[class_i] * (P_i - 0.5) + eta_LOCAL * I(local_i) * x_i] / sum_i w_i`

- `gamma[class_i]` は、その走のクラスがパーセンタイルの予測力を変える交互作用係数。新馬を基準カテゴリとし、係数は学習データだけから推定する。クラス名だけで馬を一律加点・減点しない。
- 地方走除外候補では `I(local_i)=0`。地方重み下げ候補では `eta_LOCAL` を学習データだけから推定し、地方走の実効重み `1 + eta_LOCAL` を [0,1] に制約する。除外と重み下げは別候補とし、テスト結果で選び直さない。
- 係数は、学習期間のレース勝者を目的変数とするレース内softmax（条件付き多項ロジット）の対数尤度最大化で推定する。正則化・ハイパーパラメータ選択は学習期間内の時系列分割だけで決める。

### JRA実績数による縮小

JRA有効走数を `nJ_h` とする。地方走除外候補ではJRA走だけ、地方重み下げ候補では地方走を所定の重みで含めて `S_base(h)` を計算し、

`S_shrunk(h) = [nJ_h / (nJ_h + k)] * S_base(h)`

とする。 `k >= 0` は学習期間内の時系列交差検証だけで選択する。JRA未出走はスコア0（中立）。地方走の有無・重みと縮小の有無を組み合わせて別々に評価する。

### レーティング

レーティングあり候補は、JRAの数値レーティングがある走だけから加重平均 `T_h` を求め、`rho * (T_h - 90)` を加える。`rho` は学習期間だけで推定する。JRAレーティングがない馬（JRA未出走を含む）はレーティング項を0とする。レーティングなし候補では全馬この項を0とし、欠損を代入で埋めない。

最終スコアは `S(h) = S_shrunk(h) + rho * (T_h - 90)`（レーティングなし候補は rho=0）。確率はレース内softmax `p_h = exp(S(h)) / sum_j exp(S(j))` で正規化する。実装では最大スコアを引いてから指数化する。

## 3. 別々に評価する候補

- B0：現行Bの再現。元ファイルは変更しない。
- B2-a：クラス交互作用のみ。
- B2-b1：地方走除外。
- B2-b2：地方走の実効重みを学習期間だけで推定。
- B2-c：JRA走数による縮小。
- B2-d：レーティングあり／なし。
- B2-full：a→c→bの順に追加し、レーティングあり／なしを別々に出す。

候補を混ぜて単一の「B2」と呼ばない。

## 5. データ元・時刻・完全性

- 既存履歴入力：`data/horse_history/2026-10-25.json`。記録上の取得時刻は2026-10-24 18:04:26 JST。実行記録に入力SHA256・対象馬・対象日を記載する。
