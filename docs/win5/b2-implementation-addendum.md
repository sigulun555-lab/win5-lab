## 固定する事項
1. **検証に使うレース**：JRA平地（芝・ダート）のレースで、着順が数値の出走が5頭以上、1着がちょうど1頭。障害・取消のみのレースは除く。期間は2025-10-01〜2026-10-24。人気は結果ページの最終人気（実際のオッズではない）。馬の履歴ページが取得できなかった馬は『有効な走なし（スコア0）』として扱い、レースは除かない。その件数と割合を報告する。
2. **ハイパーパラメータ（k・L2・tau）の選び方（内側の検証）**：各foldの学習期間のうち、**直近3か月を内側の検証ブロック**とし、各ブロックで、それより前の月だけを内側の学習に使う（拡大窓）。3ブロックの平均対数尤度が最大の組を選ぶ。同点の規則は仕様書のとおり。選んだ組で、学習期間全体を使って係数を再推定する。
3. **係数と、k・L2・tauの推定の順序**：候補ごとに、(L2, k, tau) の全組み合わせについて、内側の学習で係数（gamma・eta・rho）を、L2つきの対数尤度の最大化（L-BFGS-B。etaは実効重み [0,1] の範囲に境界を設定）で推定し、内側の検証で評価する。tauと係数のスケールは冗長だが、そのまま許容する（tauは正則化と合わせて、スケールの探索として働く）。kを使わない候補は、縮小なしとして扱う。
4. **地方重み下げの分母**：仕様書の式どおりに実装する。分母は `sum_i w_i`（基本の重み）のまま、地方走の寄与だけを分子で `(1+eta_LOCAL)` 倍にする（地方走の寄与を中立の0に近づける形）。
5. **クラス照合に使えるデータ**：対象走より前の日付のJRA結果データ（`date < 対象レース日`）を、日付・競馬場・1着馬で照合する。照合は一意一致のみ。複数一致・不一致は `UNKNOWN_JRA`。
6. **競馬場の別名辞書**：取得したデータの競馬場名の全種類を一覧にし、次の規則で機械的に分類して、辞書ファイルとSHA256を**係数推定の前**に保存する。JRA＝10場（札幌・函館・福島・新潟・東京・中山・中京・京都・阪神・小倉）とその2文字表記。LOCAL＝地方競馬の競馬場（帯広・門別・盛岡・水沢・浦和・船橋・大井・川崎・金沢・笠松・名古屋・園田・姫路・高知・佐賀）とその2文字表記。OVERSEAS＝国名・海外の競馬場の表記が明らかなもの。上のどれにも当てはまらない値、空欄は `UNCLASSIFIABLE`。結果を見て分類を変えない。
7. **人気順位のみの基準**：結果ページの最終人気（18位以上は18にまとめる）のワンホット、L2=0.01の条件付きロジット。各foldの学習期間で推定する。
