# win5-lab

JRAのWIN5（指定5レースの1着をすべて当てる馬券）について、GPTとClaudeが独立に「1着になる確率」を予想し、結果と照らして精度を確かめるための共同検証リポジトリです。お金を賭けない、記録上の検証です。

## フォルダ構成

| 場所 | 内容 |
|---|---|
| `rules/win5-prompt.md` | WIN5予想の手順 STEP1〜11（版 de2c6eb9c814） |
| `rules/win5-joint-validation.md` | GPT・Claude共同検証ルール（WIN5-JOINT-v1.0、暫定運用つき） |
| `app/index.html` | WIN5帳の画面。買い目計算・予想メモ・収支帳・バックテストに、Claude × GPT の比較表示を加えたもの |
| `win5_gpt_primary.csv` | GPTの一次予想（2026-10-24、全72頭） |
| `data/win5_joint/<日付>/win5_claude.csv` | Claudeの予想（全馬） |
| `data/win5_joint/<日付>/win5_joint.csv` | 両者を並べた合体CSV（共通項目は1回、`claude_` と `gpt_` の列に分ける） |
| `data/win5_races/` | WIN5帳に貯めた過去のレース記録（45件） |
| `data/win5_v1_log/` | 2026-10-24 の最初のログ（5件）。JRA公式のオッズと合わない数字を含むため、参考にしないでください |

## 運用の要点（詳しくは `rules/win5-joint-validation.md`）

- 目的は、各レースの「1着になる確率」の推定精度の検証です。配当妙味や割安度では、勝率を変えません。
- 暫定運用として、V1/V2を区別せず、締切前は最新のオッズで上書きします。更新のたびに情報取得時刻を記録します。締切後は上書きしません。
- 本命や上位の順位がずれたレースは、理由を聞き合って、納得するまで協議します。合意できなかった点は、そのまま残します。
- 購入基準は市場本命です。分析本命は検証用に記録し、混同しません。
- 的中は、各レースの1着馬が一致した場合のみです。2着・3着は的中にしません。
- 取得できない情報は「未取得」とし、推測で補いません。

## 画面（WIN5帳）の使い方

画面の「共同検証 Claude × GPT」に、GPTのCSV、ClaudeのCSV、または両方入りの合体CSVを貼ると、`gpt_` と `claude_` の列を見て自動で振り分けます。各レースの ◎○▲ と、勝率・順位のずれ、協議メモを見られます。
`app/index.html` は画面のコードです。データの保存先はClaudeのアーティファクト側にあり、このファイルを単体で開いても、サンプルの表示になります。
