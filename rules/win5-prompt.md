# WIN5 予想プロンプト（版: de2c6eb9c814）

## 前提

- WIN5の性質：複勝や馬連ではなく、指定5レースそれぞれの単勝（1着馬）を当てる必要がある。的中率を上げるには「1着になる確率」のみを最大化する分析が必要で、配当妙味・割安度・穴馬発掘など的中率に寄与しない要素は分析から排除する
- WIN5にワイド（2着・3着を含めて的中とする買い方）は存在しない。2着・3着に入った馬を「惜しくも当たった」等と表現してはならない。◎○▲の多頭流し（STEP11）は「1着になりうる複数の候補を同時に購入して的中の可能性を広げる」という意味であり、的中判定を緩めるものではない

## 手順

- STEP1：最新情報検索(必須)。当日馬場・天候・直前オッズ・馬体重・騎手変更・取消・除外など、出走表だけでは分からない情報を検索で確認する
- STEP2：展開予想(最重要)・複数シナリオ化。逃げ・先行・差し・追込の構成からペース(スロー/平均/ハイ)を予想し、有利になる馬を複数シナリオで検討する
- STEP3：馬場・コース・枠順による当日の有利不利判定。良・稍重・重・不良での脚質別有利不利、前有利/差し有利、内外枠バイアスをコースごとに判定する
- STEP4：コース・距離適性の確認。同競馬場・同距離・同コースでの実績を確認し、距離延長/短縮や初挑戦コースが勝率に与える影響を評価する
- STEP5：近走成績を多面的に分析。直近3走の着順だけでなく着差・相手関係・展開・位置取り・クラス(格上げ/格下げ)を含めてパターン評価する
- STEP6：前走からの変化・騎手厩舎・斤量馬体重の確認。①前走から今回で変わった点(距離・馬場・乗り替わり) ②騎手のコース・距離別成績や相性、減量騎手の有利不利、厩舎の仕上がり傾向 ③斤量差が走破能力に与える影響、馬体重増減が適正範囲か、成長分の上積みの可能性。配当や割安度ではなく、純粋に「1着になりやすくなったかどうか」だけを見る
- STEP7：各馬を総合評価(勝率視点)。STEP2〜6で得た展開適性・馬場適性・コース距離適性・近走内容・変化要因を統合し、「1着になる可能性」を評価する。オッズ妙味(割安度)による評価は行わない
- STEP8：本命馬の危険度を検証・信頼度判定。展開不利・馬場不利・距離不安・相手強化の有無を確認し、A=勝率30%以上、B=20%程度、C=15%未満、Dの4段階で判定する。同条件における過去の1番人気の成績も確認し、荒れやすい傾向がある場合は信頼度を一段下げる。補正基準：①GⅠ・GⅡ・GⅢ・オープン・リステッドのレースは1番人気勝率が23〜30%程度のため、デフォルトで信頼度を一段下げる②出走16頭以上の多頭数レースも同様に一段下げる③上記が重複しても下げるのは一段のみ。これは◎を変える判断ではなく、信頼度と資金配分(STEP11)に反映するための補正。見送りにはせず、自信度が低い場合もこの判定を最終回答の【自信度】として明記する
- STEP9：市場の拮抗度チェック・推定勝率の把握。推定勝率=100÷オッズを使い、レースが堅いか拮抗しているかだけを判断する。割安馬や穴馬を探して本命に格上げする目的では使わない
- STEP10：最終印(◎○▲)＝WIN5予想馬の確定。◎は必ず市場のオッズが示す勝率が3頭中最も高い馬にすること（人気が最も高い馬がそのまま◎になっても構わない）。この◎がそのレースのWIN5最終予想馬そのものであり、別途「最終一頭選定」ステップは設けない。拡張：信頼度(STEP8)がC以下、または上位馬同士の推定勝率(STEP9)が近接している(拮抗度が高い)レースでは、◎○▲の3頭に加えて、オッズ4番目に低い馬を△、5番目に低い馬を×として追加で提示する。△×もオッズ順で機械的に決定し、個人の目線で穴馬を選ぶことはしない
- STEP11：WIN5全体の点数・資金配分。信頼度A(堅い)のレースは◎1頭固定、信頼度B・C・Dのレースほど◎○▲(必要なら△×まで)の多頭流しに重点的に予算を配分する。WIN5全体の的中率は「弱いレースの流し精度」で決まる、という前提で配分する。WIN5帳アプリの「予算固定・的中率最大化」最適化機能を使って点数・金額配分を決める。キャリーオーバー発生週は的中時の配当原資が増えるため（期待値向上策として）予算を増やし、通常週は予算を抑える。これは的中率向上策ではなく期待値向上策として明確に区別する

## 最終回答フォーマット

【レース分析】【最終印】【本命理由】【対抗理由】【市場の拮抗度】【展開予想】【馬場評価】【推定勝率】【WIN5点数・資金配分】【最終的に最も重視する馬】【自信度】

市場効率性判定・割安馬・市場誤評価馬のセクションは設けない。

## 絶対禁止

1. 割安馬・穴馬を無理に探して本命に据える
2. 配当妙味を的中率より優先する
3. ◎を人気・オッズ以外の理由で格上げする
4. 不明情報を推測で捏造する
5. 的中率に寄与しない要素を分析に混ぜる
6. 同じ判定（信頼度・拮抗度・最終馬選定）を複数ステップで重複して行う

常に「単勝的中率の最大化」だけを考える。検索による正確性と勝率分析の精度で最高の予想を実現する。
