# 近走データによる補正の検証（2026-10-24）

「近走データから勝率を少し補正すると、市場より当たるか」を、JRAの過去の結果で確かめた記録です。

## 結論

- 今朝の予想に使った補正（好調×1.06、同条件の実績×1.04、休養明け×0.95、斤量の増減×0.97/×1.03 など）は、**過去の結果で効果を確認できませんでした。** 3通りの期間の分け方のどれでも、補正を掛けた場合と掛けない場合の差は、ほぼ0でした（95%区間が0をまたぎます）。
- 要素ごとに見ると、「同じ馬場・距離の実績がある」「同条件で複数回凡走している」にだけ、弱い効果の兆しがありました。ただし、期間によって有意だったり、そうでなかったりでした。
- そのため、10/24の予想は、**公式単勝オッズの正規化のみ**に戻しました。補正は使っていません。

## データと方法

- **データ**：JRA公式の「レース結果」ページ。2025年10月〜2026年10月24日、3,651レース・50,334頭。着順・人気・斤量・馬場・距離から作っています。
- **基準**：人気順位だけで1着確率を決めるモデル（条件付きロジット。各人気順位に重みをつけ、レース内で合計1に正規化）。
- **要素**：各馬の前の出走（データ内の直近4走）から作った8つの目印。
  - `form_good`：直近3走のうち2走以上が3着以内で、最悪でも5着以内
  - `form_bad`：直近3走がすべて9着以下
  - `cond_good`：同じ馬場・距離±200mの直近走で、3着以内がある
  - `cond_bad`：同条件の直近走が2回以上で、すべて8着以下
  - `cond_none`：同条件の経験が直近走にない
  - `rest150`：前走から150日超
  - `wt_up` / `wt_down`：斤量が前走比で+2kg以上／−2kg以下
- **検証**：古い期間で係数を推定し、新しい期間で「1レースあたりの対数尤度」が基準より良くなるかを測りました。95%区間は、レース単位のブートストラップです。3通りの期間で確認しています。
  - A：訓練 4〜8月、テスト 9/1〜10/24（444レース）
  - B：訓練 4〜7月、テスト 8/1〜10/24（803レース）
  - C：訓練 6〜10月、テスト 4〜5月（599レース）

## 結果

| 期間 | 差 | 95%区間 |
|---|---|---|
| A | +0.0009 | −0.0021 〜 +0.0038 |
| B | +0.0011 | −0.0014 〜 +0.0035 |
| C | +0.0001 | −0.0032 〜 +0.0033 |

| form_bad | ×0.90 | ×1.09 | ×0.98 | ×0.80 | 効果なし |

## 限界

- 基準は「人気順位」で、実際の単勝オッズではありません（過去の全馬のオッズはJRAの結果ページにないため）。実際のオッズには、人気順位より多くの情報が含まれるので、**ここで効果が見えない要素は、オッズに対してはさらに効果が小さい**と考えられます。逆に、ここで弱い効果が見えた要素も、オッズに既に織り込まれている可能性があります。
- 要素は、データ内（直近4走）で作った単純な目印だけです。展開・馬場状態・調教・騎手などは含めていません。
- 期間が1年分で、テスト期間の標本は数百レースです。要素を8つ試しているため、偶然の有意が混じる可能性があります。
- 今回の結果は「いまの要素では、市場に上乗せする根拠が見つからなかった」という意味で、「どんな補正も効かない」という意味ではありません。

## 再現

`crawl.py`（JRAの結果ページを取得）→ `parse_ses.py`（解析）→ `model.py`（検証）。`model.py` の分割は、環境変数 `SPLIT=A|B|C`（`model2.py` 相当の分割を使う場合）で切り替えました。取得したHTMLは大きいので、リポジトリには入れていません。
