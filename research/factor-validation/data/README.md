# races.json.gz（JRA公式の開催日結果ページから解析したレース結果）

- 取得元：JRA公式の「レース結果」開催日ページ（https://www.jra.go.jp/JRADB/accessS.html）。`crawl.py`（取得）→ `parse_ses.py`（解析）。
- 期間：2025-10-04〜2026-10-24、3,654レース（芝1,924・ダート1,730。障害は含まない）。
- 展開後の `races.json` のSHA256：`526ca9d57b67d72144ed8ee996e94199ecc3b048a23244c0b5c013eff03ae654`
- 1レースにつき、日付・競馬場・レース番号・クラス名・距離・馬場、各馬の着順・人気・馬ID・騎手・斤量・馬体重・通過順位など。
- 取得時刻：2026-10-24（取得は03:0x JST、10/24のレースは当日夕方に追加）。
- 使い方：`gzip -dc races.json.gz > races.json`。既存の検証コード（`model*.py`）が参照する `races.json` と同じもの。
- 1着が2頭のレースが3つある（2026-05-23 新潟5R、2025-11-16 東京8R、2026-08-16 中京11R）。事前登録の『1着がちょうど1頭』の条件では除外される。
